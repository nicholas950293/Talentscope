# Talentscope MVP 測試計畫

> 本文件區分「計畫案例」與「已執行結果」。除明確註記已於 2026-07-29 執行者外，其餘一律標為 `Not Run`，不可視為 Passed。

## 1. 測試目標與範圍

驗證目前三角色 MVP 的畫面可用性、角色導覽、題庫與組卷、驗證與作答、AI 提示紀錄、人工審核、狀態一致性、基本 RWD 與無障礙風險。

包含：

- `/` 首頁與三角色入口。
- HR 總覽、候選人、新增與結果摘要。
- 技術主管題庫、組卷、邀請與審核。
- 面試者驗證、說明、作答、提示與提交。
- 九種面試狀態名稱、表單訊息、Empty State、Toast 與 Modal。
- typecheck、SSR smoke test、vinext build。

## 2. 不在本次測試範圍

- 正式 API、資料庫、RBAC、Interview Token、Email、AI 與 Audit Log，因尚未實作。
- 多語言程式碼執行、自動判題、錄影、監控與防作弊。
- 真實併發、長時間穩定性、災難復原、SLA 與資安滲透測試。
- 正式模型公平性或招募法遵驗證。

## 4. 測試層級方向

### 單元測試方向

- 題庫關鍵字與多條件 filter。
- 題目加入、移除、排序與總時間計算。
- 九種狀態合法值與 Badge mapping。
- Demo 驗證函式、提示紀錄 shape、結果選擇。
- 未來正式狀態機的合法／非法轉移。

目前已有 `tests/demo-logic.test.mjs`，涵蓋候選人複合篩選、答題完成度與未作答清單、九種合法狀態與核心轉移、手動／逾時的單次提交保護；2026-07-29 執行 4/4 Passed。元件測試仍為 Planned。

### 整合測試方向

- `DemoApp` 角色切換與畫面分派。
- 候選人建立後 HR 列表更新。
- 題庫選取與組卷同步。
- 作答、提示、提交與完成頁。
- AI 初評與人工分數獨立。
- 未來 API 與 DB transaction、Email job、AI job、AuditEvent。

目前只有首頁 SSR smoke test，主要互動整合測試為 Planned。

## 6. 已知無法驗證的項目

- 正式權限與資料隔離：目前無後端 RBAC。
- Email 是否送達、token 是否安全／到期／撤銷：目前為 Mock。
- AI 正確性、延遲、成本、公平性與 prompt injection：目前無 AI Service。
- 自動儲存與斷線恢復：目前無持久化。前端已具單次提交 guard，但無法驗證跨請求冪等或伺服器收件。
- 多使用者跨角色即時同步與併發衝突：目前單一瀏覽器 state。
- Audit Log、個資保存／刪除、監控與告警：尚未實作。
